# Capstone Product Specification

## Overview
Autonomous research assistant that accepts a user topic, decomposes it into search queries, gathers evidence across sources, performs cross-validation, and synthesizes a cited executive briefing.

## Minimum Viable Features
- [ ] User auth & project isolation
- [ ] Stateful LangGraph orchestration
- [ ] At least 2 MCP retrieval tools
- [ ] Strict source citation markers [1]
- [ ] Human approval gate before external publishing
- [ ] Automated Ragas evaluation suite
- [ ] Docker Compose deployment
